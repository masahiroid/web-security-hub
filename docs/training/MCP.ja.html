AIアシスタントから検証を使う（MCP）

English · 遺伝的探索 · OpenVEX · 基本ハンズオン

Web Security Hub は、標準入出力で動く MCP サーバーとして使えます。MCP に対応したAIアシスタントが、検証結果の参照、検証の開始、OpenVEXドラフトの準備を行えます。この端末の中で動き、ネットワークには公開されず、起動時に許可したことだけを提供します。 ソース版（Node.js 24以上）で利用できます。

1. サーバーを起動する

先に一度ビルドし、MCPクライアントからサーバーを起動します。

npm run build:verifier
node core/verifier/generated/cli/mcp.js [--allow-run] [--allow-code-snippets] [--allow-vex]

クライアントの設定例です（チェックアウトの絶対パスを指定します）。

{ "mcpServers": { "web-security-hub": { "command": "node", "args": ["/path/to/web-security-hub/core/verifier/generated/cli/mcp.js", "--allow-run"] } } }

npm run ではなく node で起動してください。npm は独自の行を標準出力に出し、プロトコルを壊します。サーバーは標準出力にプロトコルのメッセージだけを書き、ログは標準エラーに出します。

2. 許可

許可は、サーバーを起動するときにあなたが決めます。アシスタントは変更できず、許可されていないツールは、そもそも提示されません。

オプション 許可する内容
（なし） レポートの要約とジョブの状態の参照、VEXドラフトの一覧、VEXの状態の提案
--allow-run 内蔵サンプルでの、サンプル検証と遺伝的探索の開始
--allow-code-snippets レポートの具体的な候補値と、候補ごとの結果の参照
--allow-vex VEXドラフトの作成、ステートメントの保存、人が承認した文書の取得

レポートとドラフトは、アプリを使うときと同じく、この端末の非公開領域に保存されます。

3. ツール

ツール 必要な許可 目的
list_reports なし 保存済みのレポートの種別・観測・時刻
get_report_summary なし 1件のレポートの集計（入力や値は含まない）
get_report_details 候補値 具体的な候補値と結果
start_sample_verification 実行 サンプル検証を実行し、ジョブのハンドルを返す
start_genetic_search 実行 遺伝的探索または固定ルールの基線を実行。言語モデルは使わない
get_job_status / cancel_job なし このサーバーが開始したジョブの進捗、集計結果、取消
vex_suggest_status なし 選んだレポートに違反の再現があるときだけ affected を提案
vex_create_draft、vex_save_statement VEX 未承認のOpenVEXドラフトを準備
vex_list_drafts なし 版・状態・ステートメント数つきのドラフト一覧
vex_export_document VEX 承認済みドラフトの文書を返す

4. 制限と安全策

  • 承認は人が行います。 VEXドラフトを承認するツールはありません。アプリのVEX画面でステートメントを確認して承認すると、はじめてアシスタントが文書を取得できます。
  • ジョブは同時に1つで、試行数に上限があります。ハンドルは、このサーバーが開始したジョブにだけ使えます。未知の値や不正な形式は拒否します。
  • 回数の制限（1分あたり）: 参照60回、書き込み30回、ジョブの開始6回。
  • 既定では集計だけ。 要約とジョブの結果には、件数と状態が入り、入力や値は入りません。
  • 「見つからない」からは何も導きません。 検証で何も見つからなくても「影響なし」は作られません。VEXの規則はアプリと同じです。
  • 有限の試行は安全の証明ではありません。 結果は、実施した試行についての記述です。
