コマンドを入力せずに使う

1. 環境を準備する

アプリを開くと、Node.js、保存先、診断ブラウザーを確認します。「準備が必要」と表示されたら「必要なブラウザーをインストール」を押し、完了を待ちます。初回はインターネット接続が必要です。失敗した場合は画面のログを確認し、接続を直して再試行してください。

配布アプリには Node.js が入っています。ソース版は macOS の start.command、Windows の start.bat、Linux の start.sh から起動します。ソース版の初回は実行環境と依存パッケージも準備するため、ターミナルに進捗が表示されます。システム全体の Node.js を変更したり、管理者権限を要求したりしません。

2. ハンズオンを始める

ホーム左側の「マニュアルと研修」を選び、「ハンズオン環境を開始」を押します。サンプルが起動し、training-ja / training-en の設定と架空の認証情報が用意されます。「サンプルサイトを開く」から learner@example.test / training-only でログインできます。

「画像付き教材を開く」で演習を進めます。アプリ版では教材 T01 のコマンドは不要です。上部の「ホーム」またはブラウザーの戻る操作で、この画面に戻れます。

3. 変更と修正を確認する

教材 T07〜T09 のモード切替コマンドの代わりに、ホームの「基本版」「変更版」「修正版」を使います。切替後に「診断・テストを開く」から同じセッションで再実行してください。変更版でベースラインを更新しない点は同じです。

T10 の絶対パス入力の代わりに、ホームの「静的解析の修正前例を開く」「修正後例を開く」を使います。解析画面にパスが入力された状態で開くので、「静的解析を開始」を押します。

4. 初期化・終了する

サンプルの状態だけを戻すには「サンプルを初期化」を押します。研修設定を戻す場合は確認欄をチェックして「研修設定も初期化」を押します。過去の実行結果とベースラインは残ります。

ネイティブアプリは終了時に内部サーバーと子プロセスを停止します。ソース版は起動したターミナルで Ctrl+C を押してください。設定・認証情報・レポートはホームに表示された利用者の保存先に残り、アプリ更新とは別に管理されます。

困ったとき

研修用の 4180 番ポートが使用中なら、以前起動した研修サーバーを終了して再試行します。他のプロセスを自動で停止することはありません。基本機能に ZAP、Docker、Claude Code は不要です。Linux でブラウザーの OS ライブラリ不足が表示された場合は、配布ガイドの前提条件を確認してください。

日英の教材と画像はアプリ内に同梱しています。初回導入と外部サイトの診断を除き、教材を読むためのネット接続は不要です。
