Use the app without typing commands

1. Prepare the environment

The start screen checks Node.js, writable storage and the automation browser. Select Install required browser if setup is needed, and wait for completion. The initial download requires internet access. If it fails, inspect the on-screen log, fix the connection and retry.

The packaged app includes Node.js. For a source distribution, open start.command on macOS, start.bat on Windows, or start.sh on Linux. Its first launch prepares the runtime and dependencies in a terminal, then opens the start screen. It does not change the global Node.js installation or request administrator privileges.

2. Start hands-on training

Select Documentation and training in the left sidebar, then Start hands-on environment. This starts the sample and prepares training-ja / training-en with fictional credentials. Open the sample and sign in using learner@example.test / training-only.

Select Open illustrated course. Skip the command-line setup in T01: the app has already handled it. Return using the Home link in the app sidebar or your browser's Back navigation.

3. Compare changes and fixes

For T07–T09, use the Baseline, Changed and Fixed buttons on Home instead of the mode-switching commands. Open the app and replay the same session. Do not record a new baseline while examining the changed version.

For T10, select Open before-fix SAST fixture or Open after-fix fixture on Home. The analysis screen opens with the correct source path filled in; select Start Static Analysis.

4. Reset and exit

Reset sample restores sample state. To restore training configuration too, check the confirmation and select Reset training configuration. Previous sessions and baselines remain.

Quitting the native application stops its internal servers and child processes. For source mode, press Ctrl+C in the launcher terminal. Settings, credentials and reports remain in the data location shown on Home, independently of application updates.

Troubleshooting

If training port 4180 is occupied, stop the other training server and retry. The app never kills unrelated processes. ZAP, Docker and Claude Code are not needed for the core course. On Linux, missing operating-system browser libraries require the prerequisites listed in the distribution guide.

Bilingual documentation and screenshots are bundled. Reading them does not require internet access; initial installation and scanning external sites do.
